# Contributing to AI Usage Menu

Build with Xcode and Swift 6 using `./app/build.sh`. Run `./app/build.sh test` before submitting a change. Use anonymized fixtures for parser changes. Add a provider by implementing the Provider protocol and registering it in UsageStore. Include tests for empty, expired and unavailable readings.

Describe the change, the reason for it, and how you verified it in the pull request. Keep usage logs, account files and personal activity out of issues and commits.
