# Changelog

## 1.0.3 | 2026-11-23

- Codex limits now match what Codex shows, even when a Codex session started the day before.
- When a Codex window resets, it shows 0% used instead of a dash.

## 1.0.2 | 2026-11-23

- New versions now show up as soon as you open the app, not only once a day.
- Check for updates and see your version right in Settings > About.

## 1.0.1 | 2026-11-23

- The menu bar and Dock no longer show a warning while your first reading is loading.

## 1.0.0 | 2026-11-23

- See your Claude Code and Codex plan limits in the menu bar and the Dock, with no cookie or API key to paste.
- Know when each limit resets, and whether you're on pace to run out before it does.
- See what's using your Claude limit, from activity on this Mac only.
