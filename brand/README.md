# AI Usage Menu | Aurora Gauge brand kit

Selected direction: a luminous open gauge over three ascending usage bars. The assets were recreated as editable SVGs from the supplied option reference. The files are organized for handoff to a product engineer or a website developer.

**Start here**

1. Open `09-previews/brand-kit-overview.png` for the system overview.
2. Read `01-brand-guidelines/BRAND-DEFINITION.md` for colors, type and usage rules.
3. Use `03-macos-app-icons/AppIcon.appiconset` for Xcode.
4. Use `04-menu-bar/usage-template.svg` for the status icon.
5. Use `02-logos/mark/mark-gradient.svg` for a transparent brand symbol or one of the transparent PNG exports.
6. Copy `08-design-tokens/tokens.css` or `tokens.json` into the site.

App and site reference crops are original design concepts, not verified UI screenshots. The product must replace these crops with captures from the shipping implementation before release. The live website URL is aiusagemenu.com.

Fonts are specified in the guidelines, not redistributed. The SVG wordmarks use live type and will render with Inter or a system fallback. All brand iconography is original to this kit.

Includes logo families, transparency-ready exports, macOS icon catalog, small-size menu bar assets, icon style kit, web favicon package, Open Graph image, editable colors and a simple preview page.
