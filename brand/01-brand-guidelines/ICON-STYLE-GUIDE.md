# UI icon system

- 24 by 24 SVG canvas, stroke width 1.75, round caps and joins.
- No fill except where a status indicator or simple bar requires a filled shape.
- SVGs use `currentColor` so icon colors are controlled by the parent UI.
- Use a 20 to 24 px visual size in product UI and 16 to 20 px beside small labels.
- For menu bar status items use `04-menu-bar/usage-template.svg` rather than generic `usage.svg`.
- Prefer one color per icon. Gradients belong to the brand mark, not the UI icon set.
- Keep direct provider names in text. Provided provider glyphs are original abstractions, not trademarked marks.
- Announce controls through VoiceOver with purpose, not icon-shape descriptions.

Included: usage, breakdown, reset, activity, settings, about, privacy, refresh, notification, check, external-link, provider-claude-code, provider-codex.
